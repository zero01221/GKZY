# 高考志愿助手 · 使用说明

一个**免安装、免编程环境**的高考志愿查询工具。双击即可运行，不需要安装 Python、Node.js 或任何数据库。

> 仓库地址：<https://github.com/zero01221/GKZY>

---

## 〇、两种获取方式

### 方式 A：直接下载完整发行包（推荐普通用户）

到 [Releases](https://github.com/zero01221/GKZY/releases) 下载带运行时的压缩包，
解压后双击 `高考志愿助手\启动.bat` 即可。**不需要装任何东西。**

### 方式 B：克隆源码（适合开发者）

```bash
git clone https://github.com/zero01221/GKZY.git
cd GKZY
```

由于仓库不包含 89 MB 的便携运行时（`node.exe`），克隆后需要二选一：

```bash
# 选项 1：本机已装 Node.js（>= 18），直接运行即可
node 高考志愿助手/server/server.mjs --port 8765 --open

# 选项 2：把本机 Node 复制成交付目录里的便携运行时，之后就能双击启动
tools\setup-runtime.bat
```

> 克隆下来的 `高考志愿助手\data\` 已内置院校库、大学环境数据和部分省份的分数线索引，
> 开箱即可使用「分数线查询」与「大学环境」两个功能。

## 一、快速开始（3 步）

1. 把 **`高考志愿助手`** 整个文件夹复制到任意位置（桌面、D 盘都行，**路径尽量不要包含特殊符号**）。
2. 双击文件夹里的 **`启动.bat`**。
3. 稍等几秒，浏览器会自动打开 `http://127.0.0.1:8765`，即可开始使用。

> 关闭那个黑色命令行窗口 = 退出程序。
> 如果浏览器没有自动打开，请手动在浏览器地址栏输入窗口里显示的地址。

**常见问题**

| 现象 | 处理办法 |
|------|----------|
| 双击后窗口一闪而过 | 右键 `启动.bat` → 以管理员身份运行；或查看窗口里的报错信息 |
| 提示端口被占用 | 程序会自动切换到 8766、8767…，以窗口里显示的地址为准 |
| 杀毒软件报警 | 内置的 `runtime\node.exe` 是 Node.js 官方运行时，属正常文件，请放行 |
| 页面打不开 | 关闭窗口后重新双击 `启动.bat`；或用 `停止.bat` 清理残留进程 |
| 想彻底卸载 | 直接删除整个文件夹即可（不写注册表、不留残留） |

## 二、功能说明

### 1. 分数线查询

按 **生源省份 + 科类 + 年份 + 院校 + 专业关键词** 检索。

- **院校专业组投档线**：该院校在你所在省份各专业组的最低分、最低位次、省控线、线差、选科要求。
- **专业录取分数线**：具体每个专业的最低分与位次（首次查询会自动联网获取，之后走本地缓存，秒开）。
- **历年趋势图**：点击「查看历年趋势」，用折线图展示最低分区间与省控线的逐年变化。

> 数据优先使用本地索引；本地没有的会自动向上游获取并缓存。

### 2. 大学环境

数据来自开源项目 **[colleges.chat（大学生活质量指北）](https://cn.colleges.chat/)**，是**在校生匿名问卷**的聚合结果，覆盖：

- 宿舍是不是上床下桌、几人间
- 教室和宿舍有没有空调、有没有独立卫浴
- 会不会断电断网、限电多少瓦
- 食堂价格、校园网质量、外卖政策
- 交通便利度、查寝与门禁、跑步打卡要求
- 以及「自由补充」里最真实的吐槽

搜索院校名即可查看；每条结果都附有「在 colleges.chat 查看原文」按钮。

> 本工具内置了 4500+ 所院校、3.3 万余份问卷的聚合数据，离线也能查。

### 3. 智能推荐（冲 / 稳 / 保）

输入 **生源省份 + 科类 + 分数（或全省位次）+ 意向专业**，输出三档推荐。

**两种定位方式**

| 方式 | 原理 | 适用 |
|------|------|------|
| **按分数（默认，线差法）** | 你的线差 = 分数 − 该批次省控线；与院校历年的「最低分 − 当年省控线」直接比较 | 大多数情况，不受试卷难度与省控线波动影响 |
| **按位次（位次法）** | 直接比较你的全省位次与院校历年最低位次 | 手上有官方一分一段表时，最准确 |

**分档规则**

- 🔴 **冲**：录取概率 < 45%，往年门槛略高于你，可以冲一冲
- 🟡 **稳**：45% ≤ 概率 < 80%，与你的水平相当，把握较大
- 🟢 **保**：概率 ≥ 80%，明显低于你的水平，用来兜底

每张卡片都会显示：录取概率、基准线差/位次、最近一年分数、近三年迷你趋势，以及「为什么推荐」的理由标签（985/211、历年是否稳定、门槛升降趋势等）。

> 志愿填报建议按「冲 3 : 稳 4 : 保 3」的比例搭配，注意拉开梯度。

### 4. 我的志愿

在任意结果里点 **☆** 即可加入志愿表，数据保存在本机浏览器中，支持 **导出 CSV** 与 **打印**。

### 5. 数据管理

查看本地数据覆盖情况、后台同步进度、上游接口状态。

- **本工具默认不会自动抓取数据**，避免给你的网络带来限流风险。
- 安装包已内置部分省份的录取数据（见下表）。缺少的省份可以在这里**按需同步**：
  选择省份 → 点「同步该省份」→ 后台限速抓取，**不影响你继续使用页面**。
- 想一次性补齐，可点「补齐最近三年全部省份」（耗时较长，可随时关闭程序，下次会从断点继续）。

**关于「智能推荐」的省份覆盖**

- 若某省已有本地索引 → 直接秒出结果。
- 若某省没有索引 → 程序会自动做一次**快速抽样建库**（抓取前 600 条左右），
  约 1 分钟内先给出结果，并在页面上标注「本次结果基于快速抽样数据」；
  同时完整数据会在后台继续补齐，稍后刷新会更准确。

> 「分数线查询」和「大学环境」**任何省份都能用**（实时联网获取），不需要预建索引。

**已内置数据（随版本更新）**

| 年份 | 已覆盖省份 | 记录数 |
|------|-----------|--------|
| 2026 | 见「数据管理」页实时显示 | — |
| 2025 | 同上 | — |
| 2024 | 同上 | — |
| 2023 | 同上 | — |

> 即使某省没有本地索引，「分数线查询」和「大学环境」功能依然**完全可用**（会实时联网获取）；
> 「智能推荐」会自动快速抽样建库后给出结果。

## 三、数据说明

| 项目 | 说明 |
|------|------|
| 数据来源 | 掌上高考（`api.eol.cn`）公开接口 / colleges.chat 开源问卷数据 |
| 覆盖范围 | 全国 31 省 · 2991 所院校；分数线覆盖 2023–2026 年（随抓取进度增长） |
| 更新方式 | 每次查询自动缓存；「数据管理」页可触发后台批量补齐 |
| 存储位置 | 全部在 `高考志愿助手\data\` 下，不上传任何个人数据 |

> 分数、位次等数据来自公开渠道，可能存在滞后或误差。**最终请以各省教育考试院和高校官方发布为准。**

## 四、目录结构

```
高考志愿助手\
├─ 启动.bat            ← 双击这个
├─ 停止.bat            ← 卡住时用这个强制结束
├─ runtime\node.exe    便携运行时（免安装）
├─ server\             本地服务（静态托管 + 数据 API + 推荐引擎）
├─ web\                前端页面
└─ data\
   ├─ schools.json     院校库
   ├─ colleges.json    大学环境数据
   ├─ index\           分数线索引（按省-年）
   └─ cache\           查询缓存（可随时删除）
```

**运行要求**：Windows 10 / 11（64 位），内存 4 GB 以上，约 120 MB 磁盘空间。

## 五、开发者指南（重建数据）

仓库不包含体积较大的抓取中间产物，可用 `tools/` 下的脚本重新生成。

```bash
# 1. 院校基础库（2991 所）  -> data/raw/schools.json
node tools/crawl.mjs schools

# 2. 按省抓取录取数据       -> data/raw/province_<省ID>_<年份>.json
#    --rate 控制速率，--years 指定年份，可中断后续爬（自动跳过已完成）
node tools/crawl.mjs bulk --kind province --years 2026,2025,2024 --rate 2

# 3. 下载 colleges.chat 开源问卷数据   -> data/colleges_raw/
node tools/fetch_colleges.mjs

# 4. 把问卷聚合成高校环境数据          -> data/bundle/colleges.json
node tools/build_colleges.mjs

# 5. 装配进交付目录（大数据自动 gzip） -> 高考志愿助手/data/
node tools/build_bundle.mjs

# 查看抓取进度
node tools/crawl.mjs status
```

**架构要点**

| 文件 | 职责 |
|------|------|
| `高考志愿助手/server/server.mjs` | HTTP 服务入口、13 个 API 路由、静态托管、端口自增、自动开浏览器 |
| `高考志愿助手/server/data.mjs` | 数据层：院校库、分数线索引、一分一段拟合、大学环境、磁盘缓存 |
| `高考志愿助手/server/upstream.mjs` | 上游代理：令牌桶限速、熔断退避、用户请求优先、失败不缓存 |
| `高考志愿助手/server/indexer.mjs` | 索引构建：优先级队列、断点续爬、突发-休息节流、快速抽样 |
| `高考志愿助手/server/recommend.mjs` | 冲稳保推荐引擎（线差法 + 位次法 + 正态概率模型） |
| `高考志愿助手/web/` | 前端单页应用，原生 HTML/CSS/JS，零外部依赖 |

详见 [DESIGN.md](DESIGN.md)。
